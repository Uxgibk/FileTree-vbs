# FileTree-vbs
纯文本工具，Windows 单文件目录树生成器，双击即用，零依赖。vbs应用。


## 特性

- 📄 **单文件**：整个工具就是一个 `.vbs`，拷到哪都能用
- 🖱️ **双击即用**：无需安装、无需命令行
- 🧩 **零依赖**：不依赖 Node、Python、PowerShell、Git Bash
- 🈶 **中文零坑**：源码纯 ASCII，中文用 `ChrW` 运行时构造，**文件存什么编码都不会乱**
- 🧾 **UTF-8 BOM 输出**：记事本、VSCode、Sublime 打开中文都正常
- 📊 **信息头**：txt 开头附带生成时间、路径、文件夹数、文件数、耗时
- ⏱️ **汇总弹窗**：运行结束弹出结果，N 秒后自动关闭
- 🔍 **不忽略任何内容**：完整列出一个目录下的所有文件与子目录
- 🔁 **支持重复运行**：每次生成的文件名带时间戳，不会互相覆盖


## 使用环境


| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 7 / 8 / 8.1 / 10 / 11 |
| 运行时 | Windows 自带的 **Windows Script Host (WSH)** |
| 脚本宿主 | `wscript.exe`（默认双击运行） |
| 依赖 | **无** |
| 权限 | 普通用户即可（无需管理员） |

Windows 全版本**默认自带 WSH**，开箱即用。
